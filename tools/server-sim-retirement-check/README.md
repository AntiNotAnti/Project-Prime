# Actual server simulation retirement

This Mac fixture references an explicitly selected, immutable application DLL. It uses the actual `ServerSim.Start`, native AMHE1 room construction, one direct native `Step`, and `Stop` on one owner thread. It checks six room retirements, repeated Stop, real room-load failure, pre-Scene diagnostic failure, stale replacement, and a throwing room-cancellation callback which creates another authority world before throwing. It also checks that partial failed cleanup never grants foreground facade eligibility, and that a callback may replace the world on the same ServerSim instance. The diagnostic failure uses a private directory at the actual netlog filename and a bounded reflected diagnostic writer; it changes no production test flag or user setting.

Build with `-p:PrimeReferenceDirectory=/absolute/immutable/compiled-client`, then run `run_check.py /absolute/immutable/compiled-client EXPECTED_DLL_SHA256`. The runner uses only normalized path entries through the existing `campaign_identity.isolate_user_data`, private cwd/userdata/Export, and read-only extracted assets. It copies compiled dependencies before execution and preserves the actual exit, log, result, hashes, and before/after asset identity. No credentials or settings are copied.

These are cleanup regressions, not another timed full-Run campaign. There is no UDP, GL context, account/backend request, physical client, performance claim, or save. The earlier full-Run baseline and its missing-cleanup finding remain unchanged under `artifacts/cpp05-actual-world-rml58`.
