After a shipping-feature build, run `dotnet run --project tools/rmlui-setup-engine-check -c Release --no-restore` for actual invalid-ROM and extracted-path checks. Pass the absolute packaged `rmlui` asset directory for actual native documents, layout, focus, typed intents, ROM confirmation and failure log, manual path configuration and Back checks. Use `-p:BuildProjectReferences=false` when sharing a coordinated client build. The fixture writes only to a temporary game-data root and restores it after the check. These checks do not download game files, fetch releases, or install an update; successful extraction requires a compatible user-provided ROM, and platform update installation remains a device/release acceptance check.
