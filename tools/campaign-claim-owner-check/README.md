Build against an explicit immutable `PrimeReferenceDirectory` containing the new production counter. This project has no application ProjectReference. Run separate processes with `PRIME_NET2_EVIDENCE` set to an owned private path plus argument `enabled`, and with that environment variable absent plus argument `disabled`.

It calls the actual compiled NetCampaignEvidence counter owner and actual NetHitClaims.Reset across six rounds, verifies zero/disabled behavior and preserves the authority counter meaning. The reflected scalar sets only the existing resettable diagnostic value; no gameplay claim is synthesized. Actual gameplay declaration and retry semantics remain covered by the real applied-client campaign and its source-reviewed single declaration call site. It opens no socket, world, GL context or account/backend session.
