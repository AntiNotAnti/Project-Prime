# Portable NET evidence, 2026-10-14

This package contains sanitized derivatives of existing receipts and measured data. It includes no original raw files, binaries, assets, replay demos, private host paths, credentials or full stack dumps. Every derivative has an original relative source filename/SHA256/byte count and an independent derivative SHA256 in `manifest.json`. Do not describe a sanitized file's digest as the original raw digest.

The NET03 `ad65dcd39099764114b2b4d7f1147288987312e0` classifier measurement preserves six cases and180 raw batches, including zero caller allocations in every measured batch. The NET04 `4b4b5c451a17430fcd6fadb2fe72c56b020bd570` archival measurement preserves15 cases and450 raw batches. Raw wall/process-CPU/allocated-byte values and all outliers are unchanged. The `batch-lines.sanitized.json` files retain every original `RAW` line verbatim; startup/completion paths are omitted there and structured identities remain in results.

The NET04 `fce73957396ab916cfa7ce6a462f76e3e66d24e1` qualification, native and scene receipts are separate from the earlier4b benchmark. They preserve actual qualified client identities and source/tree/closure facts. The final scene adapter reads existing4b campaign demo digests through the fce client; it does not establish that the campaign itself ran at fce. Demo files are not shipped. Native and scene scope exclusions in each original receipt/log excerpt remain part of the evidence.

The benchmark entry, full native fixture and actual client SHA256/MVID are distinct. No benchmark establishes native admission, graphics, impact coverage, payment or FPS. All percentiles are batch totals, never individual-operation/frame tails. Setup allocations are included only in the explicit fresh Begin benchmark; other fixtures are prepared outside timing.

Negative evidence stays negative: earlier NET03/NET04 compile failures, the2a recorded seed-frontier/bootstrap failure, the first external benchmark namespace compilation failure, historical configuration falsifier, and initial setup closure observations have separate portable derivatives. Later corrected results do not erase or relabel them.

Reproduction code is in `tools/net-evidence-benchmark`. It needs a separately qualified physical client/full fixture/dependencies and an external fresh output directory. These archived derivatives report the original measured commits; a future rerun creates a new entry identity and new measurements, not a replacement claim for the old data.

Inherited CLI diagnostics preserve the frame 785 client failure across frozen dc5/ad65/4b binaries and frame 682 authority failure at the fixed 2048-packet bomb queue. The corrected Headless PassiveReplayScene passes are separate and preserve all exclusions, including no pixels. Initial missing-Headless GL-binding failure stays negative.
