## Provenance and dry verification

`manifest.json` records each original relative filename, original immutable
SHA256/byte count and separate derivative SHA256/byte count. Its numeric/array
projection binds numeric/boolean/null values, array lengths and array positions;
all strings are retained except literal workspace/home prefix replacement with
`${WORKSPACE}`/`${HOME}`. The raw result files have no omitted fields. Duplicate
embedded result payloads in runner receipts, bulk source-tree lines and asset
maps are omitted with their own canonical hashes and counts; the full original
receipt hashes still bind those inputs. The complete results are separate files.

No assets, binary, runtime dependency, Paths.txt content, savedata, private host
path or allocation stack dump is included. This package is a sanitized derivative,
not the original raw bytes and not a fresh campaign.

```sh
python3 tools/life-evidence/verify.py \
  --evidence docs/evidence/life-campaign-2026-10-14

# Optional: compare every derivative with the original immutable local inputs.
python3 tools/life-evidence/verify.py \
  --evidence docs/evidence/life-campaign-2026-10-14 \
  --original-workspace-root /absolute/original/workspace
```

The optional comparison verifies original SHA/bytes, exact authorized string
transformation and every retained scalar/array value. The ordinary portable
mode checks derivative hashes, numeric structure, expected denominators,
source/client/asset/recording identities, actual failure preservation and scope
exclusions. Neither invocation loads assets or executes a game/native process.
