# Balance evidence tool

`FruityPrimeTools balance REPORT_DIRECTORY OUTPUT_PREFIX [TELEMETRY_DIRECTORY] [MIN_MATCHES=30]` reads raw MatchReportV1 JSON bodies and optionally compressed match telemetry. It writes JSON aggregates and a Markdown readout. It does not contact Backend or change game settings. Raw report schema validation does not authenticate a reporter; use exports from the validated Backend ledger for trusted analysis, and preserve that provenance separately.

Inputs are bounded to 1024 files of each kind, 1 MiB per raw report and 128 MiB total report bytes. Telemetry uses the existing 64 MiB decoded and 131072-event bounds. Duplicate report UUIDs with different exact body hashes fail; identical duplicates count once. Missing or malformed reports fail visibly. Bot-inclusive and Practice matches are excluded. No real or invented sample matches are included.

Cohorts separate exact rules, build, content hash and claimed trust. The tool reports Hunter selection counts/rates, finished-result win/tie rates, K/D, measured damage per minute, beam kills, team-index wins/ties and mean authoritative played duration. Distinct Hunter selections per participant define the pick denominator. Changing-Hunter participant totals cannot be honestly allocated across Hunters, so their K/D, damage and wins are excluded from Hunter aggregates. Departed participants retain measured combat totals but are never classified as terminal winners. Team-change matches are excluded from team-index bias results. Team index is not automatically a physical map side.

Telemetry joins only by the canonical report UUID and matching room/mode, with completed state and zero dropped events. Unknown/unmatched or lossy captures do not become zero observations. Joined metrics remain in the same versioned cohort: weapon pickups per minute, kills/damage and damage share, overtime frequency, and death within 3/5/10 seconds after spawn. A spawn's window is eligible only if the death occurred within that window or enough match time remained to observe the entire window. Pickup frequency is a control proxy, not an invented percentage of weapon availability or ownership time. Existing map telemetry commands provide spatial detail and pickup-to-kill timing.

The default minimum is 30 matches/results, reported as a descriptive threshold rather than a significance claim. Small Hunter samples stay labeled insufficient even when their cohort has enough total matches. Missing telemetry metrics remain unavailable. Use `G5_BALANCE_CHANGE_TEMPLATE.md` for a falsifiable, versioned hypothesis and rollback criteria before considering any tuning.
