# Optional original campaign credits

This SH-08B increment connects the admitted original credits, widgets, text,
results and background frames to the existing native ending page. The new
**Original campaign credits** desktop setting defaults OFF. Unsupported source
profiles, unavailable canvas support, load failures and rejected canvas packets
retain the mission receipt. It is a stacked-screen presentation, not a claim of
Second Hunt widescreen composition or DS pixel parity.

Production and test source is frozen at
`fd7e9ecb0053a907aaba3e7d89fe08430ab727ee`. The existing protocol 70, intent ABI 1
and independent optional canvas ABI 1 remain unchanged. The existing movie,
post-match commit, ending receipt, file-select return and save owners remain
responsible for their original transitions.

## Source and lifetime

The initial admitted profile is AMHE1 with English selected. Its 33 inputs total
1847932 bytes: frontend/text records, eight models including the native font,
eighteen animations, four backgrounds and ARM9. Exact byte lengths and SHA-256
identities are pinned. Font metrics use the qualified ARM9 slices and the
embedded font must match its separate admitted model. Another language or
edition is not silently replaced with English.

One page-owned load job captures the selected configuration and source identity
on the UI owner and retains the existing configured-files capability. Its worker
receives only that identity and cancellation. It reads bounded, exactly hashed
regular files and returns an immutable catalog; it creates no Model, native or
GPU owner and changes no global asset cache. Default OFF or missing native
canvas capability starts no credits job or canvas allocation.

The reader rejects rooted/traversing/NUL paths and symlink/reparse ancestry,
checks the opened regular object before payload allocation and checks exact
size, EOF and hash from that same handle. Unix NONBLOCK avoids FIFO peer waits;
NOFOLLOW rejects leaf links. Explicit reviewed 64-bit stat layouts are used for
macOS/Linux X64/Arm64; other Unix profiles refuse before opening. Windows uses
OPEN_REPARSE_POINT and classifies the same handle. This is not a race-free
ancestor walk or a deadline for ordinary/network filesystem IO. Only Mac Arm64
has runtime qualification here; other platform branches have compile coverage.

Disposal cancels without waiting on the UI thread. A continuation observes
faults and releases the configured-files capability/CTS only after the worker
finishes. A canceled or replaced page cannot adopt a late catalog, start music,
or publish native geometry. Exact document/generation, current source, current
receipt and foreground ownership fence activation and acknowledgement. A stale
identity retires the optional presentation without starting fallback music.

The UI owner admits every selected page's worst-case triangles, glyphs, sampler
policies and table budgets before constructing private mutable samplers. The
adapter preserves the frame owner's painter order and maps `(x,y)` to
`(x,192-y)` in a 256x384 virtual canvas. It drops Z only after source depth sorting,
preserves UV orientation, quantizes straight vertex color once, and coalesces
only adjacent equal texture slots. Widget/font sampling is nearest; backgrounds
are linear. Clamp/repeat S/T remain independent, unsupported mirror policies
refuse the whole profile, and native canvas performs the only premultiplication.
The owned profile needs 32 slots and 1690624 RGBA bytes. Native 64 slot/4 MiB,
65536 vertex/196608 index/4096 batch limits are independently enforced.

One monotonic presentation clock drives the source timeline at 30 Hz. Inactive,
modal-covered, hidden, zero-viewport or suspended launcher paths reset its
baseline, including periods when Refresh stops altogether. Resume performs no
wall-time catch-up. Long active hitches admit at most 250 ms/eight steps; this is
an explicit scheduling policy, not original frame-pacing equivalence. Campaign
records remain with their existing 60 Hz owner.

The existing audio session requests CREDITS on successful activation and
RESULTS on the source result transition. Failed startup or a stolen music epoch
does not retry source IO/cues every UI frame or reclaim another scene's track.
Results OK is discovered from the admitted Kind 1/call 206 action and is enabled
only when that source item is ready. Its real native `results:close` intent is
accepted once. Application cancel stays available during loading, credits and
results and retires the presentation before the existing controller returns.
No arbitrary original callback becomes an executable application callback.

## Remaining acceptance

Windows SSH authentication is unavailable; the requested fallback is macOS.
There is no physical Android/controller/touch proof, Linux runtime proof, or
Mac sampler-object branch proof. Android package/AOT compilation does not
activate an Android ending-page owner. This increment does not add that owner.
Full Gorea movie→save→receipt→credits journeys, live audio/device behavior,
original widescreen/crossfade fidelity and the original cockpit remain outside
this scoped proof. The setting stays optional and OFF until full campaign and
device acceptance. The overall integration plan remains incomplete.
