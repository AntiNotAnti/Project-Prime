# Local Scout Drone Ready presentation

Alpha and Gamma imported drones have a separate local presentation owner in
explicit solo Scout Drone practice. Hunters saves Native/Alpha/Gamma independently
of its local body choice. The preference is captured only for Weavel's solo
Battle/playtest with native movement, zero bots and the existing private drone
mechanics. Ordinary matches, combat/arsenal practice, online and replay do not
activate this selection. A selected missing or corrupt import refuses before
creating the match Scene.

This is Ready flight/hover presentation only. Native burst, laser, morph,
status, damage flash, transparency, shadows and other unsupported pictures use
the complete native Psycho Bit model. Native laser strips are submitted on both
paths. The source selection grants no ability, projectile, collision, movement,
damage or scoring authority. Seven Hunter IDs, protocol83 and replay shapes stay
unchanged; full imported character integration remains unfinished.

## Exact source and actor ownership

The independent v1 bundles from [PR966](https://github.com/AntiNotAnti/Project-Prime/pull/966)
remain byte-identical. Separate closed profiles bind each own GLB, provenance,
animation bank, raw graph, CINF and material archive. AlternateForm admission is
explicitly separate from the existing source ball profiles and Biped/cannon
owners. Alpha/Gamma never borrow a Trooper35 or Echoes39 rig.

Each appearance renders all1,390 triangles, all33 joints and both original
opaque GX material groups. Whole-rig evaluation feeds independent25/12-joint
batch palettes within the existing32-matrix shader limit. No joint is truncated.
The same-generation bank retains100 roots/88 strict roots/85 declared roots;
only ordinal13 `B_ready_drone`, ANIM `b45b6445`, is admitted by this runtime slice.
Its raw SHA256 is `d714b3f01328ad897a82ed67de2f3e20e0922283bd9e453c269939684cc46cb0`.

`CharacterSourceDroneSelection` captures/validates the committed generation on
the load worker. The actor binds after the native drone model is initialized
by `LoadScene`. A separate sealed owner pins Scene lifetime, local main slot0,
solo player counts, native model, exact pack/appearance and current GPU attachment.
The small internal presentation-owner interface preserves existing body,
cannon and ball currentness. Bootstrap admission remains structural before the
GPU model is published.

Source root pinning is adapted from pinned MIT SecondHunt
`41452f2d053fcfa679e33c00a73d120a53f59e61` (Copyright2020 NoneGiven; LICENSE
retained). The existing Trooper derivation math is unchanged behind a shared
private helper; the drone has its own closed33-joint Ready wrapper. It deep-copies
raw channels, freezes root3 at CINF bind, removes linear root/pelvis XY travel
and centered sway mean, and preserves pelvis4 height. Basis conversion follows
the captured source hierarchy. Raw banks, viewer motion and shared rigs remain
unchanged.

The fixed filtered Ready0 Skeleton_Root pivot is approximately
`(0.0530300025, 1.7403560024, -0.0261819911)`. Each actor derives it once, then
applies its negative translation, positive scale0.3 and native interpolated
position/facing with source-only clamped aim pitch. The native model still
receives its original scale0.45 transform. This is a source pivot policy, not an
AABB fit or a change to native collision dimensions.

The owner advances only at the existing completed, unpaused60Hz boundary and
only in supported Ready states. Its loop phase is `completedSteps/60d % Duration`,
using original Duration1.2999999523162842 rather than the slightly shorter final
key time. Draw and extra pictures do not step it. Native life changes reset the
presentation clock. Step/Draw use captured inputs without filesystem reads.
Lost import proof/GPU context cannot reload from Draw; Scene/player/native drone
retirement disposes the source attachment and geometry.

The source sampler's existing1e-7-second offset is retained, including its use
when deriving keys and sampling the derived clip. Mathematical RootPin/basis
agreement does not imply bitwise agreement with donor serialized float playback.
