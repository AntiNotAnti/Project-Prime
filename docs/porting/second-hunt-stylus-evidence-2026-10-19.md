# SH-01B: Direct and Classic touch response

The existing Android raw-delta owner now offers Direct and Classic in Controls / Touch overlay / Stylus Response (controls.txt: touch_stylus_response). Direct remains the default and preserves next-simulation-step sampling, short flicks and movement released between steps. Classic is an explicit opt-in DS-style timing response: a ten-step contact hold and eight-step moving average at canonical60Hz. Sustained angular gain, physical pixel units, sensitivity, inversion, zoom and pitch limits remain in their existing owners. No second gesture model or shot-aim producer is added.

The response runs only for biped touch aim. Native morph-ball contact, rolling/swipe steering and boost bypass it. Classic suppresses raw late-presentation preview so the reticle cannot turn ahead of the filtered canonical aim. Last-contact UP resets Classic history even when UP/new-DOWN both occur between simulation samples; Direct keeps its accumulated released movement. Lifecycle/ownership resets clear both paths. Raw source activity still feeds the existing input-source tracker before response filtering, preserving aim-assistance ownership. Invalid persisted responses fall back to Direct; nonfinite/pathological platform deltas are bounded before reaching aim.

The timing reference is [Second Hunt1578a87](https://github.com/BountyHunterKanden/SecondHunt/commit/1578a87f8e6a828ed6eefb1704efb3717eb1da52), implemented over Project's existing physical-pixel accumulator. The original repository MIT notice is retained in LICENSE. This is timing compatibility at Project's established sensitivity, not a new claim of exact cartridge/emulator angular calibration.

Proven on Mac fallback: touchcheck passes Direct immediate/released-flick exactly-once consumption, Classic hold/filter/sustained gain, between-sample release/recontact, no render-only Classic bypass, native morph isolation and invalid values. The existing30Hz gesture tape now runs at30/60/120/144/240Hz requested presentation. Independent source-level reproduction caught the contact-history defect; it passes after the fix. Release compilation and final rebased input/Android verification are recorded in the integrated status.

Unproven: physical Android latency/feel, high-DPI/controller device combinations and actual in-game visual/combat/replay acceptance. No measured latency improvement is claimed: the prior Project Direct path was already immediate. Classic is opt-in, direct weapon targets remain off by default, and neither response changes protocol/replay layouts, native damage, movement defaults or60Hz cadence. Rollback: choose Direct, or revert this follow-up. This completes the response implementation portion of SH-01B, not its physical-device activation gate.
