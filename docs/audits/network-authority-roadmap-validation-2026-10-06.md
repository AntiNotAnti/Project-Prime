# Network authority roadmap implementation and validation

This note records B08–B14 and P01/P02 from the engineering audit. Source changes were made in the isolated `codex/engineering-roadmap` worktree. Protocol 41 packet layouts, full snapshots, owner-supplied movement, claim grace, and native gameplay tuning remain intact. Claims remain enabled. No attack clients, external traffic, deployment, or production-data changes were used for validation.

## Native attack evidence

Beam evidence is detached from mutable projectile pool objects. `NetAttackPaths` retains collision-trimmed native segments, native explosion centres and the shared native ice-wave shape. The authority generates the paths through `BeamProjectileEntity.Spawn`; it does not invent homing, ricochet, cluster or micro-missile trajectories. A world collision trims the segment before it can support a historical victim behind that obstruction.

Every beam type, including Imperialist, needs native evidence. No guessed reach ceiling from the parent weapon table supplements this mandatory witness: native child, homing and ricochet paths determine their actual reach. Matching uses source-relative native travel age with a two-frame tolerance; an old ACK cannot borrow a projectile passage from a different source time. Continuous events instead require their exact admitted phase. Body/turret flags must match the historical body actually intersected. Non-Imperialist headshots retain the native 15-unit range limit; the Imperialist optional unscoped penalty retains the existing native halving of both body and head damage. The stale invariant was corrected to match native code, without a balance change.

Protocol 41 prediction reports the victim's position rather than an exact impact point. The existing two-unit reported-position admission tolerance remains compatible with that producer, while independent native contact proves the hit. Durable resolved-shot facts use the canonical native witness point and native impulse direction. Claimed impulse magnitude cannot exceed its native component. Splash excludes the direct-hit victim; direct and splash claims cannot charge the same component twice against one victim, including a historical direct-contact rescue.

`EmitPending` (`NetAcceptedAttacks.cs:379`) emits accepted but missing native shots once, including a valid shot whose shooter has since died. Recovered continuous events use `NetFireEvents.BeginAcceptedEmission` to restore exact phase, preserve monotonic consumption and restore temporary event/target state on exceptions. A shared continuous beam is processed before the next recovered pulse replaces it. Native children inherit source identity and native travel age. The witness component counter is authority-only and does not mutate while private replicas step.

Anonymous alt attacks retain native accepted-phase evidence. Bombs must be actual native bombs, temporally matched to their accepted source, with exact historical victim contact volume and actual damage. Lockjaw connection/snare checks use native bomb positions and native geometry. Bomb and contact hits intentionally preserve the native absence of a victim line-of-sight rule; beam splash retains its native line-of-sight check. Human-form recovered edges cannot arm an alt attack. Contact geometry shares `NetContactLagComp.Intersects`, rather than a free distance envelope.

Evidence and work are bounded: 1,024 admitted attacks per slot, 512-frame attack lifetime, 16 deferred carrier events, 8,192 native samples per slot, 1,024 indexed shot heads, at most 512 sample examinations per query, 16 native components per attack/victim, and bounded source/bomb/contact histories. Overwritten or unavailable evidence cannot create claim damage. These bounds preserve owner movement and native claim rescue; they do not disable the claim feature or introduce movement reconciliation.

## Validation evidence

Tests used the extracted retail assets read-only, a private headless scene and in-process values. The standalone runner is a temporary DLL-only wrapper around repository check entry points; it sends no network traffic. Final server compile used the installed .NET SDK, `--no-restore -m:1 -p:MphReadServer=true`, and passed with 37 warnings and zero errors in 48.91 seconds (`/tmp/prime-network-server-race-final.log`). The parent task owns the combined final client/Android and complete contract runs.

The final ownership review added deterministic constructor failure coverage: repeated attempts on an occupied ephemeral endpoint, release/rebind, and an injected thread-start failure after binding. That test checks that disposal tolerates a never-started thread and immediately releases the socket. Its 11 initial assertions passed on the refreshed DLL, including immediate port reuse after both bind and unstarted-worker failure. Repeating the check exposed a real receive/dispose race: `UdpClient.Dispose` clears `Client`, so the worker could dereference null after its running check. Both receive and send now retain the actual native socket reference; disposal yields the already-handled socket-disposal exception. Thirty-two immediate constructor/dispose cycles were added to each policy run. Three independent runs passed all 503 assertions, including 96 total immediate disposal cycles. The original repository eight-peer localhost transport stress check also passed against the fixed product DLL. These tests create local listeners and perform no sends.

## Remaining evidence limits

The implementation is covered by native and pure regressions, but this host has not exercised every hunter/modifier/weapon combination across a real protocol-41 delayed-carrier network matrix. In particular, exact delayed native homing/ricochet/cluster and all anonymous alt attacks need release soak coverage under loss/reordering and the existing grace policy. Missing evidence is a refused rescue, never extra damage; count refused/geometry/resource outcomes during that soak to detect valid-hit regressions. The older arbitration stress fixture must not be presented as that coverage.

Authored source movement/muzzle pose remains owner-supplied under the finite-state policy. The exact FireEvent source pose is independent of the newer carrier/body position; when the source carrier was lost, protocol 41 has no separate retained source body position to establish that coupling. Native evidence bounds damage, path and resources under the accepted source pose. It does not prove movement legitimacy or fully server-derived source-position legitimacy. A speculative displacement envelope would reject recovered fire during valid movement/teleportation and is outside this change.

Pacing measurements are local macOS evidence. Windows/Linux under load and multiple simultaneous dedicated processes still need equivalent CPU/p99 measurements before changing thresholds. Directory reachability and DNS tests are deterministic policy/lifetime checks, not public-network or NAT measurements. No protocol or movement architecture migration was introduced.

The replay late-carrier repair was reviewed separately: on-time/private streaming fire cursors can suppress quiet carriers, but an unknown late fire requires a checkpoint strictly before its authored source, invalidation of later stale capsules, and bounded reconstruction in an unpublished private world. A source older than retained reconstruction state must yield an unavailable history contract. Root owns those replay changes and their parity tests.
