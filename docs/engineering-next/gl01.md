
## Measured native baseline

On Apple M4 Pro/macOS27.0/GL2.1, one25-second High-shadow eight-player1920x1080
profile produced34 retained windows after the actual240-simulation-step marker
and four additional completed windows. This fixed convention is used before
candidate selection; a profiler presentation-only warmup flag is insufficient.
GPU timers are unsupported. Median window work:49.048 palette requests/frame,
9280.4 copied floats,37.9 repeated consecutive preparations covering7453.8
floats (80.3%). Palette collection median window p95 is0.018333ms, so total-frame
headroom is small. Existing uniform caching already skips5898.47 of7353.01
scalar requests/frame and37.48 matrix-array requests; real array uploads are
50.98/frame and27670.8 bytes/frame. Per-program/pass/setup-owner partitions are
present and conserved, with unknown sources explicit.

Five clean unprofiled12-second baselines on the same immutable client completed
with zero dropped simulation steps/stalls and approximately60Hz simulation.
Median completed-frame intervals: p50=1.9248ms, p95=2.9620ms, p99=3.7631ms.
Full per-run samples are in gl01-results.json; these are baselines, not gains.

Negative evidence retained: a symlinked harness initially loaded the baseline
client (old MVID), so that profile is excluded. Initial unprofiled runs with
possible simultaneous build activity were preserved and repeated cleanly.
An initial41-window aggregate that used only the presentation warmup flag was
replaced by the simulation-marker/four-window analysis. No favorable sample was
dropped. Windows/Linux/GLES hardware performance, full graphics matrix, first
person/morph/replay/editor and exact native parity remain NOT_RUN for this slice.
