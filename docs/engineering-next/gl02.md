# GL-02: collection-local palette preparation

**Disposition: NO_ROLLOUT. The experiment remains off by default.** The cache removes repeated palette scaling while preserving each item's independent snapshot. Exact native image/depth comparisons passed in the two measured fixtures, but repeated unprofiled native frame-time tails worsened. The arithmetic microbenchmark and profiling reduction do not justify enabling it.

The candidate is a bounded 512-float collection-local scratch keyed by source identity, positive native revision, matrix count and bitwise scale. It clears on collection boundaries/unload. Unknown revisions, partial/oversized sources and nonfinite scales use the original indexed scaling loop. Existing palette revision write-boundary contracts remain required; arbitrary mutation without a revision increment is not certified. No uniform uploads, geometry ordering, simulation or GPU-resource ownership changed. `PROJECT_PRIME_GL_PALETTE_PREP=1` opts in; ordinary startup and forced legacy keep it disabled.

## Fidelity and negative evidence

The same immutable candidate with the flag off/on produced exact decoded RGBA equality for 18 world/HUD/repeated-world PNGs and bitwise equality for 11 world/shadow float-depth files: 29 comparisons PASS. Simulation frames240/540/840/1140 match. Fixtures: eight bots/High/1080p/Samus and solo/Off/720p/Kanden in reverse arm order. Both arms retired actual owned GL names, cleared current program and released retained buffers, textures, FBOs and glyph/sprite resources. This scope does not certify every hunter/morph/view/preset/replay/editor/GLES path.

Initial ten A/B runs and two profiles accidentally launched the baseline-bin harness and loaded the baseline MVID; they are preserved EXCLUDED. A candidate file hash did not prove which assembly was loaded. Accepted reruns use physical harness files beside the candidate, check loaded MVID and retain unchanged binary/content hashes. No favorable or unfavorable valid sample was discarded.

Focused tests passed unknown/mutated arrays, revision/count/scale changes, bounds/nonfinite/partial inputs, exception rollback, independent snapshots and source release. Client/server Release, default/opt-in/forced-legacy retained-graph and backend checks passed. The synthetic checksum-equal zero-allocation benchmark is recorded as arithmetic evidence only. Windows/Linux/GLES native performance and full render/lifecycle matrix remain NOT_RUN; hosted builds do not substitute for that hardware.

Rollback immediately by omitting the opt-in flag or setting it to0. Revert the PalettePreparationCache/collection integration to remove the experiment; there is no settings/save/protocol migration. Existing enabled render optimizations, and opt-in DEPTH_VERTEX/PROCEDURAL_STREAM policy, remain unchanged. GL-04 must retain the default-off decision unless a future candidate passes repeated tail, fidelity and device gates.
