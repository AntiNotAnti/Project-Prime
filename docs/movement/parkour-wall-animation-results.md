# Wall movement animation

Dedicated procedural wallstrafe, wallrun and wall-kick poses extend the existing native Hunter rig overlay. Airtucked wallstrafe preserves tucked legs; first-person cannon movement provides a restrained matching cue. Native camera, firing-arm pose, collision and Parkour v5 gameplay retain ownership. See the [protocol85 contract](../network/parkour-wall-animation-version-contract.md).
