## Authority and form findings

`NetLifecycleTracker` preserves `_dead` across waiting/spectating and refuses same-life `Alive`; restore validates the tombstone before changing any fields. These are existing invariants.

`PlayerReplicationBridge.ApplyAuthorityForm` rejects older samples and older transition starts, tracks owner-pending transitions, and waits up to 120 host frames before recovery from a refused/lost owner transition. A local owner normally receives `ModApplyAuthorityTurret`, while remote players receive `ModApplyAuthorityForm`. This already addresses round-trip-old owner animation rewinds; no replacement reconciliation subsystem was added.

An owner self-death reconciliation path already exists in `TryApplyIntent`: current generation/life matching is checked before `ShouldReconcileOwnerDeath`; authority, state-present, not-in-play, not-spectating, spawned and positive server health are required. It invokes the existing native self-death damage path. No owner-death packet or authority extension was introduced here; the pre-existing intent behavior merits separate adversarial/full-integration testing rather than being described as new authenticated death proof.
