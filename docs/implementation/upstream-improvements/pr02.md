### PR-02: Optional local owner camera/gun capture
- Reuses DemoRecorder full-match writer and the existing first-person render pose. Environment gate `PRIME_REPLAY_OWNER_CAPTURE=1` allocates a fixed optional buffer only at recording start; opted-out capture has no new allocations, files or packets.
- Actual rendered first-person camera view, final world/weapon FOV and drawn gun position/basis are sampled after the render pose decision. Canonical frame plus local render elapsed seconds distinguish display samples from 60 Hz authority ticks. No claim of recorded animation/cosmetics: those remain reconstructed, explicitly labelled.
- Independent `.ownerpose` schema 1/timebase 60, SHA256 replay identity and payload checksum; 65,536 samples maximum (~9.1 MB on disk). At capacity it retains the bounded prefix and later playback falls back. No compression/performance benefit claimed.
- Canonical writer completes before background sidecar hashing/writing. Optional save errors cannot fail the canonical replay. Bounded finishing captures; no per-frame I/O or owner-pose networking. Existing v3/v6 selection unchanged.
- Background bounded loading validates file length/count before sample allocation; schema/timebase/finite rigid camera matrices, unit gun basis, monotonic clocks and checksum. Sampling uses the recorded picture at/before canonical time, at most one tick old, with exact match/epoch/slot/generation/life. No cross-life interpolation.
- Playback applies camera/gun presentation only. Simulation positions, health, shots, receipts, RNG, checkpoints and replay packets never read the sidecar. Headless, third person, missing/corrupt/stale segments fall back. Exact video export explicitly retains authority reconstruction so asynchronous loading cannot change its policy mid-export. Instant clips currently use authority reconstruction too.
- Studio combat inspection shows `Owner captured · camera/gun; animation reconstructed`, `Authority reconstructed`, or `Partial/legacy`. Replay rename/move/delete includes the new sidecar.
- Validation: zero-warning Mac client/nettest build; `nettest --replay-owner-track` passes 48 real codec/identity/bounds/backward-seek/corruption checks. Core old replay, shot-payload, timed-shot archival and lifecycle suites pass; detailed results in integration report.
- **Experimental implementation; qualification pending:** actual enhanced recording/playback/seek GPU campaign, capture CPU/GC/frame pacing/bytes-per-minute, exported owner perspective, full animation capture and physical Windows/Linux/Android are not accepted by these synthetic tests. Keep capture gate off for normal release qualification. No all-player or server-owner streaming.
- CI queued/unverified; user requested immediate merge. Rollback: leave capture gate unset and remove/ignore optional sidecars.
