## Integrated instance implementation
Root subsequently completed bounded stable-ID extra instances: 21 deterministic legacy controls plus up to 11 extras (IDs1000–1010). Optional `touch_instances_v1` records preserve old positions, geometry, action semantics and downgrade controls; malformed records discard only extras. No instance records are introduced until layout editing/reset/publication. Geometry clamps finite normalized bounds; primary and extra controls independently retain pointer identity and shared-action held counts. Reload and resize cancel stale pointers.

Existing Avalonia canvas supports duplicate/add, select/tap/next, reassign, toggle, delete, drag/pinch/resize/reset with detached Apply/Cancel. Native RmlUi extends the existing 32-target visual editor and staged rows with extra action, visibility and geometry plus duplicate/delete/action/toggle controls. Instant Clip remains the existing DemoClip ring, lengths and postroll, using the bounded press-edge queue.
