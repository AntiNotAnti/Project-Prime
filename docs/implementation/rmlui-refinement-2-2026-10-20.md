## Shared interaction and performance review

`Host/RmlUiPageManager.cs` already captures/restores modal focus, gives initial focus to new pages, rejects background/duplicate/delayed intents, caps modal nesting and cancels document-bound work. No demonstrated defect warrants replacing this ownership protocol. Full Settings only removes redundant focus queries by reusing its existing per-refresh focus string; it does not add a persistent cache. Social (`NativeSocialFriendsPage.cs:137`), Party (`NativePartyPage.cs:145`) and License (`NativeLicenseOverviewPage.cs:136`) already gate publication on source revisions/dirty state. Campaign Ship (`NativeCampaignShipPage.cs:86`) does too. Their unchanged idle state does not justify a list-rebuilding rewrite.

The shared theme uses lightweight colour/opacity transitions; reduced-motion rules disable animation and transitions. Existing visual states must remain geometry-stable. New density rules are limited to installed RmlUi capabilities; no browser-only layout feature, virtual list infrastructure or renderer replacement is introduced. CPU/geometry evidence cannot establish FPS, GPU cost or real frame pacing.

Density targets retain readable controls: spacious uses available wide-screen composition, standard targets 1920×1080 ordinary menus with no avoidable scroll, compact permits intentional scrolling while preserving controls at 1280×720/short logical viewports. Accessibility preferences can increase required content height; retaining access takes precedence over hiding overflow.
