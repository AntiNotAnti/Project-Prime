# Parkour v3 version contract

Live protocol 79 selects Parkour profile v3. Protocol 78 recordings retain profile v2; protocol 77 recordings retain profile v1. Earlier protocols cannot select Parkour.

Packet IDs and widths, bit 19, and protocol 77 tuck and pivot boundaries remain unchanged. Discovery, replay format and checkpoint allowlists include protocol 79. Historical fixtures and registry baselines remain intact.

Wallrun and fresh-press wall kicks are local-owner/native-bot controllers. They
reuse native integration and collision; remote authoritative puppets retain the
existing life-fenced owner-position contract. No new authoritative trajectory
resimulation is claimed. Current short full-body wall probes validate the
retained native contact before gravity reduction and kick admission. Only
current safe static standing support refills the 45-tick airborne budget.

Passive replay worlds consume accepted canonical positions and shapes, with
physics/input disabled. They do not recreate current wall forces. The stable
passive checkpoint schema is unchanged; it is not an active-controller save or
resumable movement-budget format. An eventual active-controller save feature
must persist remaining budget and controller clocks separately.

[Windows qualification](../movement/parkour-wallrun-results.md) records the
committed producer, controller tests, clean/faulted multiplayer, retained/current
replay checks and bounded performance diagnostics. CI status remains separate.
