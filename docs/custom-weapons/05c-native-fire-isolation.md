# CW-05c — native fire at custom source boundaries

The authority filters native FireEvents before native source proof, accepted-shot
intake, replay capture and relay. Physical Shoot/Zoom, movement and inline input
history remain intact. Custom-capable sources always use the event stream, so a
legacy held-button path cannot bypass selection ownership.

Each slot has bounded storage:64 waiting carrier copies and2048 remembered full
shot identities. Events with unresolved source selection wait through64 authority
worlds; an accepted Equip rejects native fire at that source, while an accepted
Unequip can release a later native event. An older native source remains eligible
after a later Equip. Release uses the original carrier and authenticated connection
through native recovery; it never advances current movement or custom input.
Connection replacement cannot adopt waiting work. Event validation and native
carrier lifecycle validation precede gate mutation.

Permission and admission are separate. A source permitted to fire is not claim
authority until native intake accepts its exact immutable event. Conflicts,
overflow and refused special-event intake cannot publish an accepted event or
authorize a Shadow-mode claim. Relay and recording retain only admitted events.
Canonical autonomous turret emissions use their existing authority-authored fact.
Unknown occupants without custom readiness retain the native-only path.

Custom ownership guards native claim ingress, deferred resolution, payment and
Imperialist headshot correction independently of optional native proof modes.
Confirmed custom readiness requires native admission even before the first life
or source journal is opened; an early claim cannot inherit native-only fallback.
Claims arriving before the event retain their ordinary arrival-time eligibility
and wait for exact native admission. The retained event must match the beam,
launch ACK stamp and continuous phase. Immutable terminal receipt replay remains
idempotent. Bomb/alt-form admission retains its existing form-specific rules.

Rejected/unadmitted identities retain their original256-world tombstone window;
admitted identities retain1024 worlds independently of optional proof settings.
This covers native flight (up to510 fixed steps), recovery and claim arrival/grace.
Retries and admission confirmation never refresh first arrival. The2048-entry
limit accommodates a sustained60Hz stream across the inclusive retention horizon,
plus bounded recovery/turret work, without unbounded storage.

This slice completes authority native-fire isolation. Public selection bindings,
local fire suppression, HUD and optics remain subsequent CW-05 work. Developer
feature flags remain off by default; replay enablement remains CW-12.
