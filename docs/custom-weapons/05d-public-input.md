# CW-05d — public custom input and local native isolation

The optional custom slot has three separately bindable controls: custom weapon,
custom reload and custom optic. They are unbound by default. Keyboard controls,
controller actions and optional touch buttons enter one fixed-step control model.
Native direct selections, next/previous, affinity, last weapon and a native wheel
release explicitly request Unequip, including selecting the existing fallback.
The existing native wheel sectors and action IDs retain their meaning.

The public online producer receives only action kind and optic. It derives source,
identity, life, sequence and acknowledgements from the canonical client state.
The router runs after native slot/life adoption and kill-camera filtering and
before native intent capture. Accepted/denied control facts reconcile selection
and optic predictions even when several results arrive between input samples.
Bootstrap, manifest or complete owner replacement retires old predictions.

An unresolved Equip fences local native emission, charge, repeat fire and native
scope. Unequip releases that fence only after canonical settlement. Lost readiness
preserves an uncertain fence; a new life cannot inherit the old body's fence.
Ambiguous reordered Equip chains cannot regain native emission merely because
the most recent request was denied. Physical Shoot/Zoom and movement remain
available to native source proof. Authority playback is excluded from local
suppression; the CW-05c source gate remains the authority's admission policy.

Offline input queues at most16 current-step actions per granted player and commits
in order after actual player movement and aim. It captures the current gun vector
and engine muzzle at emission. Unprocessed, dead, morphed or replaced-life work
expires without delayed emission or payment. Selection changes preserve already
accepted custom flights. Resources and damage use the existing canonical runtime.

The bolt rifle submits one Fire per physical press. Holding Shoot, receiving a
denial or rendering another frame never retries it. Optic changes precede a
simultaneous Fire; reload predicts an unscoped presentation. The model supports
hold edges without retrying denied held requests. Public hold settings, scope
magnification/sensitivity, HUD and visual/audio prediction are CW-05e work.

This is control integration for an explicitly granted/ready custom loadout.
The offline grant and online custom capability remain opt-in. It does not enable
packages, replay, arbitrary custom selection in native-only matches or final
release flags. Physical controller/Android and rendered acceptance remain release
gates; synthetic input is identified as such in the evidence.
