# CW-12f10 — passive custom weapon presentation

This extends the explicit resource-owned inspection factory from
[12f9](12f9-historical-scene-resources.md). Ordinary custom file playback,
recording, native world capture and custom Scene restore remain closed.
Qualification is recorded separately in [the evidence](evidence/CW-12f10.md).

The replay Scene projects held-weapon/HUD values only from its complete custom
accumulator and matching accepted native generation/life/health. It requires
the exact retained historical package. No live readiness, input projection,
download, inventory grant, hit resolution or damage payment participates.
Before input processing, recorded custom selection suppresses native biped
firing; that passive branch does not reset the live continuous-targeting owner.
Stopped/invalid inspection sessions expose no stale held HUD or effects.

Rifle kick, flash and bolt poses derive from retained accepted launch recording
frames. Baseline flights do not invent a launch age. Reload magazine pose uses
accepted source-tick progress only: source ticks and authority world ticks are
different clocks, and repeated authority tables can contain identical source
snapshots. Neither a quiet authority Clock nor draw alpha advances reload.
This intentionally leaves reload interpolation between source updates absent.
Sampling is read-only and cold CWRS restore preserves its inputs; no new mutable
animation owner or checkpoint format is introduced.

Pickups draw from historical layout positions and accepted availability. Flight
geometry uses the accumulator's recorded authority-clock positions, without
collision, live muzzle attachment or a second projectile simulation. Bounded
contact copies retain original recording frames, source bootstrap, accepted
outcome and known launch direction (explicit zero when unknown). Contact order
is stable by recording frame/action identity. Recent canonical health impacts
draw sparks; existing cosmetic head-hit/death tracks receive matching accepted
victim facts mapped to recording time. Those tracks cannot set health/death;
accepted native snapshots remain their owner. Presentation buffers are bounded
and released with the Scene.

This adapter is silent. Custom cue/audio ownership is still unqualified.
Contact/headshot/death Scene qualification requires actual multi-client capture;
pure contact values do not establish that acceptance. Rendering observed
prefixes does not establish world capture, restore, file reopen or archive seeks.
