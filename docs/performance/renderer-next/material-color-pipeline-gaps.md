# R22 color and alpha contract

The gaps recorded during native qualification have been implemented in the explicit, scene-local `LinearColor` mode. See [implementation and Windows validation](r22-implementation.md).

Original remains off/default, existing settings migrate to off, and choosing Original disables the option. The older `MATERIAL_CORRECTIONS` experiment remains independent. Desktop Windows checks qualify the tested path; Android/GLES device visual acceptance is not claimed. No preset or automatic rollout is enabled.
